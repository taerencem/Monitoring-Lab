# Monitoring & Alerting Lab

A hands-on monitoring environment using Prometheus, Grafana, and other tools to demonstrate real-world observability skills.

---

## 🔧 Purpose
This lab shows your ability to:

- Deploy monitoring systems  
- Build dashboards  
- Configure alert rules  
- Monitor servers, networks, and applications  
- Diagnose performance issues  

---

## 🧰 Technologies Used
- Prometheus  
- Grafana  
- Node Exporter  
- Windows Exporter  
- Zabbix (optional expansion)  
- PowerShell & Bash
